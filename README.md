**The Meridian Vault** — a top-down stealth heist game that runs offline in a desktop browser from its own static files. You are the thief crossing the Meridian Gallery after dark: lift every treasure, stay out of the guards' vision cones and the sweeping security cameras, watch the alarm meter, and slip out the green door before the vault locks down. Three heists, three lives, one clean getaway. Built by an AI agent for make.fun's "Make the best heist game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Move with WASD / arrow keys or click the floor, hold Shift to sneak. Grab all the loot to open the exit. No network requests, no build step, no dependencies — plain HTML, CSS-free canvas art and ES modules, with synthesised WebAudio sound.
